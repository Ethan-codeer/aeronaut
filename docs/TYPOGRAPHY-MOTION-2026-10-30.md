# 常规字体与轻量动效调整

按用户2026-10-30要求，在现有V1.3.1上增量调整，保持页面布局、五大导航、业务数据、题库、模型、素材授权和本地进度逻辑。

## 字体

恢复原有 Arial / PingFang SC / Microsoft YaHei / sans-serif 字体栈，以 --font-ui 作为统一入口。替换机型标题、机场代码、英文标语、公式、滑杆标签与性能调试文字中的 Georgia 或额外等宽字体，取消英文标语斜体。数字采用常规直立字形；可比较的数据保留等宽数字对齐。Leaflet 控件也使用同一字体栈。未下载或安装新字体。

项目专属设计 Skill 同步记录用户偏好，不再建议将衬线或斜体字体用于展示机型与数字；锁文件中仅更新自有 Skill 的内容哈希。

## 动效

- 页面打开及站内切换：240ms 的轻微淡入（opacity 0.88 → 1），直接使用 Web Animations API；服务端输出和不支持该 API 的浏览器始终正常显示内容。
- 鼠标悬停：卡片上移2px、图片小幅缩放、目录链接右移3px。仅在精确指针且支持 hover 时启用；触屏不依赖悬停。
- 按钮：轻量悬停/按压反馈，不延迟操作、不依赖动画结束事件更新状态。
- 窄屏导航：180ms 的轻淡入与4px位移，焦点和展开语义即时生效。
- prefers-reduced-motion 启用时关闭新增 CSS 和页面动效；动画进行中改变系统设置会取消当前页面动效。连续切换路由与卸载也会取消前一动画。

不使用视差、逐卡片滚动入场、持续装饰动效或新的动画库。页面动效容器没有路由 key，也没有 transform，不为播放动画而强制重挂子内容或改变地图/3D定位上下文；不遮挡、禁用控件。

## 验证

- 全部110项测试通过，包括新增的路由切换保持子组件状态、旧动效取消、减少动态效果设置、运行中设置变更、API缺失与隐藏标签页检查。
- 生产静态构建及TypeScript检查通过。
- 278条应用路由、347个关联页面/资源检查通过；6个不存在路由按预期返回404。
- Chromium在1366、1024、768、390、320px宽度，检查首页、机型列表/详情、机场列表/详情、图库、升力与仪表页和机尾挑战：无横向溢出、无脚本错误，目标文本的计算字体均为常规Arial字体栈、font-style为normal。
- 实际站内切换记录到240ms页面淡入；菜单有预期动画；开启减少动态效果后，路由无新增动效、菜单animation-name为none、卡片hover transform为none。搜索、深色模式与图片署名正常。

本次浏览器检查为Linux Chromium，不代表真实iPad Safari、VoiceOver或设备帧率验收。
