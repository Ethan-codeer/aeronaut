# AERONAUT V1.1 交付记录

## 增量范围

保留原项目与Sites身份、导航、设计系统和已有功能。新增15家航司档案、航司搜索筛选、机型与航司双向关系，以及代码/地理/涂装/Logo四类挑战，共53道题。Logo的3个授权图形各有完整与局部题。题目与选项随机化，当前测试保留即时反馈、解析、分数、正确率和结果页。

识飞机原11张照片全部检查：有直接型号文字的照片不入题池，无法确认的照片待复核，原百科素材不受影响。标准2题（A380/A350），局部2题（747机头/777机尾与主起落架），均不要求仅靠照片区分精确子型号。专家模式保留扩展模型但不开放。新增A350真实照片不含直接型号文字，CC BY-SA4.0、摄影Md Shaifuzzaman Ayon。未重绘或模糊飞机。

删除逐题错误的保存、列表、入口、筛选、查询分支和机库区域。原来的5项成就本身均不依赖错题，全部保留。旧数据迁移至version2并保留原存储键、收藏、浏览、总成绩和实验状态；旧逐题字段不读取、不导出，其他localStorage键不受影响。

- `app/atlas/[slug]/page.tsx`：反向航司入口。
- `lib/progress.ts`、`lib/progress-store.ts`、`components/hangar.tsx`：安全迁移及移除逐题记录。
- `app/academy/page.tsx`、`app/world/page.tsx`、`app/credits/page.tsx`：新增入口与署名。
- `tests/v11.test.ts`、`tests/storage.test.ts`、`scripts/check-routes.mjs`：新增完整性和迁移验证。

12家航司Logo、9家涂装照片待授权素材补充。个别机队关系使用二手资料；Qantas官方页面部分执行器访问503，来源核对限官方搜索索引，页面已注明。现有机型数据缺口、无实时航班、无账号及无云同步不变。网站为静态Sites，适合当前浏览器本地互动与数据快照。
