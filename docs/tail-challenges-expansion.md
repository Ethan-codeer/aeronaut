# 看机尾猜航司：20题扩充

保留原2题，新增18张经过局部显示检查的真实摄影题，合计20题、13家航司。新增题来自已收录的授权涂装照片，不加入推测的航司关系。不同题可展示同一家航司在不同照片中的历史或特别涂装。

题库来源、许可、摄影署名复用涂装档案；每张题图使用不含答案的挑战文件名。JPEG副本移除描述性元数据，保留原像素；WebP副本原样复制并确认不含EXIF/XMP/IPTC。原有图库与图片署名保持完整。题前保留作者和许可，答题后展示原作来源、辨识说明及航司百科链接。

显示窗口以原图像素坐标校准，记录在 data/tail-challenges.json；SVG使用显式裁剪路径，防止不同宽高比下窗口外的机身或背景文字进入视野。并未把整张涂装照片当成机尾局部题展示。

专用机尾挑战每轮随机排列全部20题，选项也随机排序。普通知识、识机、航司综合挑战继续沿用每轮10题。图片失败仍可重试或跳过，失败题不计分。

新增回归测试检查20张独立图片、题目与航司答案、授权字段和显示窗口边界，并完整完成20题、验证答前不显示来源答案及最终20题成绩只保存一次。实际发布前另进行生产构建和浏览器验证。
