# AERONAUT 独立 3D Explorer 技术验证

## 结论与范围

原项目支持客户端Three.js与GLB静态资源的构建、打包和本地HTTP加载。本次实现选择**直接Three.js + GLTFLoader + OrbitControls**，只新增独立路由 `/lab/3d-explorer`。原首页、导航、百科、其他交互组件、用户数据存储和Sites项目身份未修改。

这是一份**有代码、有模型、有本地验证，但尚未完成真实设备与Sites托管运行验收的原型**。不得把下面的静态验证、CPU离线渲染、DOM模拟或本地HTTP结果写成真实iPad Safari/WebGL性能结果。

原Sites：`appgprj_6ada268b654c8191b201e4eb06f67da7`；原正式网址：<https://aeronaut-v1.ycwang1110.chatgpt.site>。基线提交 `7607f66e72779410a5dacc8922bab1a22ac91a63`，正式发布仍为原V1.2保存版本4。隔离分支为 `prototype/3d-explorer`，工作目录 `/workspace/sites/aeronaut-3d-prototype`；修改前Git恢复包位于 `/workspace/backups/aeronaut-before-3d-prototype.bundle`。本次为本地草稿，禁止自动部署。向原Sites绑定的默认源码分支同步被自动审批拒绝，因此尚未生成新的Sites保存版本。

使用顶点焊接、资源去重、清理及按“语义部件+材质”合批。没有为了凑面数而过度简化机翼和发动机，也没有贴图纹理依赖。已经低于原型1MiB/40,000三角面的预算，暂不引入有损简化或额外解码链。24个模型绘制批次、一个线框地面；浏览器的实际绘制调用在诊断面板读取，离线mesh数量不冒充实测draw call。

默认节能DPR≤1、绘制像素≤800,000；平衡DPR≤1.5、像素≤1,500,000。不启用MSAA、阴影贴图、后处理、环境贴图或自动旋转。实际GPU显存不可通过标准浏览器API精确读取，诊断中只显示几何上传和单套色彩/深度帧缓冲的预算估算，未包含驱动、浏览器和双缓冲开销。

## 可用交互与加载生命周期

- 默认SSR输出2D图片和启用按钮。点击后才执行动态import，随后下载模型；GLB请求附清单哈希作为缓存版本参数，避免后续更新命中旧模型；初始首页和原型页面脚本均不包含Three运行时代码，也没有GLB preload。静态检查不等同真实浏览器网络瀑布。
- 单指旋转、双指捏合缩放的OrbitControls配置；另有键盘左右/＋/−/Home、缩放与旋转按钮。
- 整机、机头、机翼、发动机、俯视五种预设，独立重置按钮。
- 下载进度、模型解析/首帧阶段提示；20秒超时、HTTP错误、200 HTML假资源、模型大小/格式/完整性校验、WebGL2不可用、上下文丢失与重试。
- 2D图为同GLB的离线渲染，WebGL缺失时仍有内容；JS组件下载失败也保留2D。用户可取消加载或退出3D。
- 只在视角/尺寸变化时提交一帧；无damping、无常驻动画循环。离屏/后台停止渲染；退出页面、取消或切换2D时清理控制器、监听器、几何体、材质、renderer并释放上下文。
- 用户主动触发5秒测量时才连续渲染：先预热0.5秒，记录提交帧数与耗时，结束恢复观察视角。可导出该浏览器实测JSON；不保存到个人机库或localStorage，不上传设备信息。
- “启用至首帧”包含组件代码加载、GLB下载与初始化，但测得的是CPU提交时刻，不是屏幕呈现/GPU完成。下载和解析另计。帧率计数也不等于GPU硬件定时结果。
