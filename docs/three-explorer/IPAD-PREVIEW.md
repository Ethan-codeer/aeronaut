# iPad Safari 正式站试用

本次用户已明确授权将集成后的3D Explorer发布到原Sites正式地址进行测试。待部署成功后，在iPad Safari打开：

https://aeronaut-v1.ycwang1110.chatgpt.site/lab/3d-explorer

也可从“飞行实验室 → 3D飞机探索”或页脚进入。当前Sites接口没有独立非生产预览地址，正式发布需使用用户明确给出的本次授权。

1. 首次打开应先看到2D图，点击“启用3D探索”后才下载模型与Three.js组件。
2. 单指拖动、双指捏合，尝试机头、机翼、发动机、俯视和重置。画布外应可正常滚动网页。
3. 先使用默认节能画质；需要时切换平衡画质。横竖屏均观察模型与按钮。
4. 展开诊断，运行5秒测量并导出JSON。请同时记录iPad型号、iPadOS版本及网络。帧率是提交计数，显存为估算。
5. 退出3D应返回2D图；再启用、切后台后回来或刷新页面，检查恢复是否正常。

如3D失败，2D图和其他网站功能仍应可用。请把错误提示或导出的JSON提供给开发者。测试尚未执行时，不预填真实设备结果。

## 开发者本地复现

源码目录中运行npm ci、npm run build、npm run preview:ipad，可启动只读局域网预览服务器。iPad需和开发电脑处于同一可信Wi-Fi，再打开服务器打印的私有IPv4网址；远程工作区localhost不是用户设备可访问地址。该方法不调用Sites部署。
