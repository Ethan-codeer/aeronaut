# AERONAUT V1.3.1 Hybrid UI/UX

使用仓库中的 aeronaut-design-system、frontend-design、ui-ux-pro-max；本次用户明确授权实施并直接发布，覆盖上次仅配置 Skills 任务的“不发布”范围。保留原 Sites 项目、公开访问权限、URL 与静态导出架构。

## 设计决定

电影感深蓝用于首页影像与全站导航；Editorial 层级、留白与易读正文用于百科与机场资料；精确、清晰的控件用于挑战、地图和实验室。采用现有深蓝、纸白、正文墨色及经过对比度调整的蓝色，不下载字体或新增动效库。英文机型标题使用已可用的 Georgia，中文阅读与控件沿用系统无衬线字体。

首页重新安排视觉层级，以原有已授权 A350 照片作为完整的视觉主体，保留显示裁切与作者来源。新增 747-8I 模型渲染入口与静态图署名，进入原有按需模型页面。探索工具以目录式布局展开，保留所有入口。减少重复滚动入场动画，让静态内容立即可读。

主导航明确为探索首页、飞机百科、航空挑战、飞行实验室和航空世界；航空词典成为始终存在的工具入口，所有原词典 URL 保留。我的机库保持工具入口，手机使用带无障碍名称的图标。窄屏菜单支持展开、收起、Escape 关闭并返回焦点、焦点离开时关闭，以及当前栏目 aria-current。

新增 app/hybrid.css 作为有明确边界的版本样式层；保留已有结构、CSS 模块和交互，避免为重构外观替换业务实现。修正机型图片署名链接原先继承整图高度的问题，避免遮盖机型链接；保留署名且扩大图注可读性。统一主要标题、阅读宽度、正文行距、图片布局、筛选区、资料卡、题目按钮与深浅主题。手机探索入口纵向排列，升力公式自适应字号与换行。输入字号16px、主要触控目标44px，减少 iPad Safari 自动缩放和误触风险；未禁用用户缩放。

## 保留范围

未修改飞机/机场/涂装/航司/词典数据库、稳定 ID 或资料来源；不删除页面，不改变子型号关联和素材许可。不恢复错题/复习系统。收藏、机库、聚合地图与拖动锁、20题机尾挑战、机场挑战、实验室与八个机型按需 3D、结构选取、静态降级及概念配色切换继续使用现有实现。无平台迁移、无依赖添加。

## 验证

- 105 项 Vitest 测试通过，其中增加导航目标、词典/机库可发现性、当前栏目及 Escape 焦点行为的回归检查。
- Next.js 生产静态构建通过（含 TypeScript 检查）。原路由与关联资源检查运行结果见本轮交付消息。
- Linux Chromium 检查1366、1024、768、390与320px宽度，覆盖首页、百科、机型详情、机场地图/详情、图库、词典、机尾挑战、实验室及机库。先修正发现的手机目录与公式溢出，再复测。
- 实际完成20道机尾题并核对20/20计分；实际检查地图锁定、机场搜索/资料卡、图库筛选与模型链接；八个机型成功加载、结构选择和整体复位，模拟模型请求失败后保留静态图片。
- 主要语义色对比度计算：muted/white 5.88，muted/canvas 5.52，white/primary 5.79，dark muted/surface 8.24，dark button text/accent 9.57。仅说明这些色对，不宣称全站 WCAG 认证。

真实 iPad A12X 的 Safari 引擎、触控、帧率、发热及 VoiceOver 未在本环境实机验收；桌面尺寸模拟不能代替这些检查。原有机场详细资料与图库数量缺口不因这次 UI 修改而被视为已补齐。
